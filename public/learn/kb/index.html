三、时间不够时按这个顺序砍 ​

  1. L4 Agent 与工具生态 —— 岗位名的来源，也是我 YYHelp 项目的主战场（LangGraph 状态图、ReAct 循环、工具契约、长期记忆、MCP）。面试官会按「你做过什么」深挖，这一层答不上来直接崩。
  2. L3 RAG 与检索 —— 企业需求量最大，我的两个项目都在这。会被连问三层：切片策略 → 为什么这样切 → 评测集多少条怎么构造。
  3. L6 评测与可观测 —— 大多应届生答不出「你怎么证明改了以后变好了」。我在 YYHelp 里做了配对 t 检验 + Holm 校正 + 三态退出码的回归门禁，这是我的差异化点，必须能讲透。
  4. L1 大模型原理 —— 会被问 Transformer / Attention / KV Cache / GQA / 位置编码。答不出「显存怎么算」会被判定为只会调 API。
  5. L2 提示工程 —— 看起来简单，但「结构化输出四条路线各自保证什么」能筛掉大部分人。
  6. L5 工程化 —— 流式、并发、限流、缓存、容器、成本归因。
  7. L7 进阶 —— 大模型开发岗要，Agent / 应用岗可以后置。
