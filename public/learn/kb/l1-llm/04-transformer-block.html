Transformer 完整结构：残差、LayerNorm 与 FFN ​

覆盖知识点：L1-07 ｜ 面试频率：高 ｜ 建议学时：8h

一句话说清 ​

一个 Transformer Block = 多头注意力子层 + 前馈网络子层，每个子层外面套残差连接、前后接归一化。残差让梯度能直通底层、让「多加一层」最坏也只是变差一点；归一化把激活尺度钉住，让深网络能训。Pre-LN 把归一化放在子层输入侧，是现代大模型的标准选择（训练更稳、可以不预热）；Post-LN 是原始论文的写法，表达力略强但必须配学习率预热。FFN 是逐位置（position-wise）的两层 MLP，在现代大模型里它的参数量约为注意力的 2 倍——模型的容量大头不在注意力，在前馈网络。

为什么必须学 ​

这一页是面试官用来分辨「看过 Transformer 图」和「理解 Transformer 为什么能训得动」的分水岭。三个高频考法：

  1. 「画一下 Transformer 的结构」——图能画出来不算过，要能标出每一处的归一化位置和形状。
  2. 「Pre-LN 和 Post-LN 有什么区别，为什么现在都用 Pre-LN？」——这题的正确答案涉及训练稳定性与梯度尺度，答「Pre-LN 更好」会被继续追问「好在哪里」。
  3. 「Transformer 里参数量最多的是哪部分？」——很多人答注意力，其实是 FFN。这个数字能不能自己推出来，直接反映你有没有真做过参数估算。

此外，这一页的所有组件都要在你手写 TinyTransformer 时一个一个落地，形状写错就是这里没吃透。

核心内容 ​

一个 Block 的完整数据流 ​

设输入 。现代 Decoder-only 大模型的 Block（Pre-LN 写法）：

两个关键结构：

  • 残差连接（x + 那两项）：把子层的输出加到输入上，而不是替换。
  • 归一化在子层内部（Norm 作用在子层的输入上）：这是 Pre-LN 的定义。

整个模型：Embedding + 位置编码 → N × Block → 最终 Norm → LM Head。

注意最后那个 Norm：Pre-LN 结构下，最后一层的输出没有经过归一化就被残差带出来了，所以堆完 层之后必须再加一个 final norm 才能接 LM Head。这个小细节在手写实现里漏掉，会让 loss 曲线明显变差但不报错。它也是判断「真的实现过」的一个很好的试金石。

残差连接：为什么它能拯救深度 ​

第一层作用：梯度高速公路。 考虑 ，对 求导得

反传到第 层的梯度是连乘 。展开这个乘积，每一项里都至少有一个 ——也就是存在一条从损失直接通到任意浅层的恒等路径，不经过任何非线性变换。这就是为什么几十层甚至上百层的网络还能训得动。没有残差时，梯度是纯连乘，深层的梯度要么指数衰减（消失）要么指数爆炸。

第二层作用：恒等映射的默认行为。 如果某个子层什么都没学到（），那 ，多加一层最坏也只是「不变得更好」，而不是「变得更差」。这让加深网络的风险大幅降低。

第三层作用：残差流（residual stream）视角。 换个角度看，整个模型维护一条宽度为 的「主通道」，每个子层从这条通道读（通过 Norm 后的输入）并往里面写（通过加法）。注意力负责在位置之间搬运信息，FFN 负责在每个位置上做逐位置的非线性变换。这个视角在解释 LoRA、可解释性（激活探针）时都很好用，说出来是加分项。

注意：残差连接不改变形状（ 进、 出），所以任一子层只要保证输入输出同形状即可插入。这是它能被复用的前提。

LayerNorm 与 RMSNorm ​

LayerNorm（LN）：对一个 token 的特征维（ 这一维）做归一化——

其中 是沿最后一维（特征维）算的均值与方差， 是可学习的缩放与偏置（长度 ）。

关键点：归一化在哪一维上做。 LayerNorm 是每个 token 独立归一化的——不同 token 之间没有统计依赖，因此与 batch 大小、序列长度都无关。这是它相对 BatchNorm 的根本优势，也解释了为什么 NLP 用 LN 不用 BN：BN 在变长序列 + 小 batch + 生成式推理（batch=1）的场景下统计量完全不可靠。

RMSNorm：去掉均值中心化与偏置，只按均方根缩放——

改了什么、为什么能省：

  • 去掉了 的计算（省一次跨维度的 reduce）与 参数（省 个参数/层）。
  • 实验观察是「均值中心化对效果贡献很小，缩放才是关键」 —— 这是它成立的经验依据，说出来要标明这是经验观察而非定理。

收益：计算更简单（少一次均值统计与一次减法），在长序列 + 大模型下这些逐元素的 reduce 省下来的时间是可观的；同时少了一组参数。代价是理论上少了一点表达能力（没有可学习的偏置项），实践中被广泛接受。

Pre-LN vs Post-LN ​

Post-LN（原始论文）Pre-LN（现代主流）
结构 的原始版是
归一化位置残差相加之后子层输入侧（残差分支内部）
恒等路径被 Norm 阻断（残差要先过 Norm）纯恒等，不经过任何变换
训练稳定性差，深层需要学习率预热好，可以不预热或只需很短预热
输出尺度逐层被 Norm 钉住随层数累积增长（残差流方差随深度增加）
最终输出已是归一化过的需要额外的 final norm
表达力略强（有实验认为同参数量下上限更高）略弱但更稳

为什么 Pre-LN 成了主流：它保住了纯恒等路径。Post-LN 里残差相加后的输出立刻被归一化，梯度回传时那条「恒等高速公路」上多了一个 Norm 的雅可比矩阵，深层的梯度尺度问题重新出现。Pre-LN 把 Norm 挪到残差分支内部，主通道完全干净，因此可以稳定地堆很深。

代价要说清：Pre-LN 的残差流方差随深度累积增长，这让不同层的激活尺度不一致，对量化（尤其是训练后量化）不友好。这是后来一些工作重新审视 Post-LN 或引入额外缩放的原因。能主动说出这个代价，说明不是只会背结论。

实践中的口诀：Pre-LN 训练稳、必须先做，是工程上的默认选择；Post-LN 是理论上的原始形态，考试会被问，落地不用。

为什么有效：门控让网络能按输入内容动态调节通道的通过量——注意力机制决定「看哪里」，门控决定「放多少信息通过」。这是一个条件计算（conditional computation）的轻量实现。

代价必须一起说：三个权重矩阵（）而不是两个。为了保持与 ReLU-FFN 参数量相当，会把 缩小约 （常见的做法是把 取到合适的对齐倍数）。这不是随手调的数——不缩小 的话参数量会涨 50%。

工程细节（能说出来很加分）： 通常会向上取到某个倍数（如 128 或 256 的整数倍），为的是让张量核心的矩阵乘维度对齐，避免尾部 padding 浪费算力。这是「参数量估算」与「实际配置」之间经常对不上的原因。

面试常问的收束：「SwiGLU 多了一个矩阵，参数量为什么没涨？」答案是同时缩小了 。这一问能区分见过名字和真读过配置。

Encoder 与 Decoder 的结构差异（回顾） ​

同一套 Block，差异只有三处：

  1. 掩码：Encoder 双向（无掩码），Decoder 因果掩码。
  2. Decoder 多一个 cross-attention 子层（K/V 来自 Encoder）。注意：它是第三个子层，同样有自己的残差 + Norm。
  3. 位置编码的注入方式：通常只在输入端注入一次，而不是每层都注入。

和你自己的项目对上号 ​

① 你的显存与成本估算需要知道参数量在哪。 项目二有成本报告与压测。当你估算「一个模型加载进显存占多少」时，最粗的算法是「参数量 × 每参数字节数」：fp16 约 2 字节/参数、int8 约 1 字节、int4 约 0.5 字节。注意这是权重部分，推理还要额外算 KV Cache（下一页）。能当场说出「FFN 占参数量的约 2/3、注意力约 1/3」——这让你在解释「为什么 7B 模型 fp16 加载要十几 GB 权重」时有依据，而不是背一个结论。

② 量化选型与 LayerNorm 的关系。 你做成本报告时会遇到「能不能用更低精度」。归一化层是量化敏感区：它的输出要经过缩放，而 Pre-LN 结构下残差流方差逐层累积，导致不同层的激活动态范围差别很大，用同一组量化参数就会在深层掉精度。这是「量化时要对某些层保留高精度」这条工程经验的原理来源。你把这条原理和自己在项目二里做的精度/成本权衡联系起来，能从「我调过 API 参数」升级成「我理解量化的代价结构」。

③ 逐位置 FFN 解释了流式的可行性。 YYHelp 用 SSE 流式返回。FFN 是逐位置的——不跨位置交互，所以新生成一个 token 时只需要算这一个位置，不需要重算整句（注意力那头靠 KV Cache 复用历史）。「逐位置」和「KV Cache」是流式低延迟的两个必要条件，一个负责不重算位置维，一个负责不重算时间维。这两句合起来是很扎实的答案。

④ 残差流视角与 LoRA 的落点。 你第 8 页会学 LoRA。它的可插拔性来自本页的残差结构：每个子层的输出是「加到主通道上」的，所以给 这些投影加一个低秩增量，效果自然叠加进残差流，不需要改动其他部分。提前建立这个联系，学 LoRA 时会顺很多。

可执行的小实验（参数量核算）：从任意一个你能读到的开源模型配置文件里取出 hidden_size、num_hidden_layers、num_attention_heads、intermediate_size、vocab_size，用本页的公式手算总参数量，再与模型实际参数量对比。判据：误差应落在几个百分点内（差额来自 bias、embedding 是否共享、norm 参数、以及 的对齐）。算不对就说明某个结构假设错了——这个调试过程本身就是最好的学习。

面试怎么问 ​

Q1：画一下 Transformer 的结构，说一下残差和归一化的位置。

A（要点）：一个 Block = 多头注意力子层 + FFN 子层，每个子层「Norm → 子层 → 加到主通道」。Pre-LN 下归一化在子层输入侧，主通道是纯恒等路径；堆完 层后必须再加一次最终 Norm 才接 LM Head。形状全程保持 。

加分句：「残差的作用不是『防止过拟合』，而是提供一条梯度直通的恒等路径：，展开连乘后每一项里都含 。同时它让子层的默认行为是恒等映射，加深网络最坏只是不变差。」

别说：「残差是为了防止梯度消失」就完——这句话是对的但太浅，会被追问「为什么能防」。

Q2：Pre-LN 和 Post-LN 的区别？为什么现在都用 Pre-LN？

A（要点）：区别是归一化在残差相加之前还是之后。Post-LN 的输出被 Norm 钉住但阻断恒等路径，深层训练不稳，需要学习率预热；Pre-LN 保住纯恒等路径，训练稳，可以不预热，但残差流方差随深度累积，所以需要 final norm。

加分句：「代价也要说：Pre-LN 的激活尺度逐层增长，对不同层的量化不友好 —— 这是它相对 Post-LN 的真实短板，不是只赢不输。」

别说：「Pre-LN 是改进版所以更好。」没有机制的比较会被追问到底。

Q3：RMSNorm 是什么？比 LayerNorm 省在哪？

A（要点）：去掉均值中心化与偏置项，只除以均方根。省的是：一次跨特征维的均值统计、一次减法、以及 参数（每层 个）。成立的经验依据是「均值中心化对效果贡献很小，缩放才是关键」——这是实验观察，不是定理。

加分句：「这也解释了它为什么在大模型上更流行：省下的 reduce 在长序列上被放大，而参数量的节省虽然小，但乘以层数也可观。」

别说：「RMSNorm 就是简化版 LayerNorm，效果一样。」「效果一样」是没有依据的断言。

Q4：Transformer 里参数量最多的是什么？

A（要点）：FFN。注意力四个投影是 ，FFN 在 时是 ，正好是注意力的 2 倍，约占单层参数的 2/3。

加分句：「用 SwiGLU 时 FFN 是三个矩阵，所以会把 缩小到约 来保持参数量不变 —— 这说明架构选择本身就是围绕参数量预算做的。」

别说：「注意力最多。」这是最典型的错答。

Q5：为什么用 SwiGLU 而不是 ReLU？

A（要点）：门控。 让网络按输入内容动态调节通道通过量，是一种轻量的条件计算。代价是三个矩阵，所以必须同时缩小 。括号里还要提工程细节： 会向上取到对齐倍数以配合张量核心。

加分句：「它是拿参数量换表达力的交易，而且交易是明码标价的：三个矩阵换一个更小的中间维度，总参数量不变。」

别说：「因为 SwiGLU 激活效果更好。」不说机制等于没答。

Q6：LayerNorm 和 BatchNorm 有什么区别？NLP 为什么不用 BN？

A（要点）：归一化的维度不同。LN 沿特征维、每个 token 独立，与 batch 大小和序列长度无关；BN 沿 batch 维，依赖 batch 内其他样本的统计量。NLP 不用 BN 的原因是：序列长度可变导致统计口径不统一；小 batch 下统计量不可靠；自回归推理时 batch 常常是 1，BN 的 running statistics 与训练时分布不匹配。

加分句：「LN 的『每个 token 独立』这个性质还带来一个工程好处：推理时可以任意 batch 拼接，不会因为 batch 组成不同而改变某个样本的输出。这对流式与动态 batching 的服务非常重要。」

别说：「BN 不适合文本。」不说维度差异就是空话。
