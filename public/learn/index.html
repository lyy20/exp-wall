这个站是什么 ​

你亲手做完了两个项目，但「做过」和「讲得清、扛得住追问」之间还有距离。 这个站的作用只有一个：把这两个项目从头到尾重新学一遍，同时把缺的知识体系补上，并且保证你随时能翻。

三条主线：

主线内容入口
项目线YYHelp v2 与科研文献 RAG，逐模块拆到源码级，附全套原理图项目拆解
知识线L0–L7 分层知识地图，每个知识点一页，能画图的都画了图知识体系
面试线高频题库 + 项目深挖预演 + 数字口径面试准备

怎么用（30 秒版） ​

  1. 打开 start.cmd —— 站点跑在 http://localhost:3000，全离线。
  2. 按左侧栏顺序读 —— 项目拆解是按学习顺序编号的，不是按重要性堆的。
  3. 右下角有助教 —— 读到卡壳的地方直接问，它能检索站内笔记再回答。
  4. 每读完一页 —— 去 进度看板 打钩；面试被问到的新题回填到错题本。

关于助教 ​

助教用 DeepSeek，API Key 只存在本机 D:\AI-Learning\.env 里，请求路径是「浏览器 → 本机 Express（3000）→ DeepSeek」，Key 不会出现在网页里。 它的人设是资深 AI 开发工程师，可以问它：讲原理、对项目、出题考你。

换 Key 或改模型

编辑 D:\AI-Learning\.env：

  • DEEPSEEK_API_KEY= 你的 Key
  • DEEPSEEK_MODEL=deepseek-chat（可换其他 OpenAI 兼容模型名）

改完重启一次 start.cmd。
