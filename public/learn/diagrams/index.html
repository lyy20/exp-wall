Agent 核心架构 ​

Agent 是什么、怎么跑起来、循环怎么终止、多个 Agent 怎么协作。这一组是 AI Agent 岗的必答题。

图类型一句话
Agent 架构全景架构图把一个 Agent 拆成模型、工具、记忆、规划器、执行器五块，说清谁在什么时候调用谁。
ReAct 循环时序时序图Reason → Act → Observe 一轮一轮怎么转，以及它为什么会停不下来。
Plan-and-Execute 工作流流程图先一次性拆解任务再逐步执行，比 ReAct 少绕路但更怕计划本身是错的。
多智能体协作拓扑架构图Supervisor、Network、Hierarchical、Sequential 四种协作形态，以及各自什么时候会变成灾难。
工作流 vs Agent架构图同样是 LLM 应用，什么时候该写死流程，什么时候才该让模型自己决定下一步。
Agent 记忆系统分类架构图短期 / 长期、原文 / 摘要 / 向量，四种记忆形态各自的成本与保真度。

框架与运行时 ​

LangChain 的抽象分层与 LangGraph 的图执行模型。面试官问「你用的框架底层做了什么」，答案在这一组。

图类型一句话
LangChain 抽象分层架构图Model I/O、Retrieval、Chains、Agents、Memory、Callbacks 六层抽象，以及它们的依赖方向。
LangGraph 运行时架构图State、Node、Edge、Checkpointer、Store 五件套，以及一次 invoke 在图里到底走了什么。

工具与协议 ​

Function Calling 的消息往返、MCP 的三层架构与授权、一次工具调用从发起到落库的完整生命周期。

图类型一句话
Function Calling 消息往返时序图从工具描述进 prompt，到模型吐出 tool_calls，再到结果回灌的完整四段往返。
MCP 三层架构架构图Host / Client / Server 三层，以及 Tools、Resources、Prompts 三类原语各管什么。
工具调用生命周期状态图一次工具调用从被模型选中，到参数校验、执行、幂等保护、结果回灌、审计落库的六个阶段。

大模型基础 ​

Transformer 整体结构、单个 Block 内部、注意力数据流与张量形状、一次推理的完整管线。大模型开发岗必考。

图类型一句话
Transformer 整体结构架构图Encoder-Decoder、Decoder-only、Encoder-only 三种形态的分工，以及为什么今天的大模型几乎都是 Decoder-only。
Transformer 单个 Block架构图一个 Block 内部从输入到输出的完整数据通路：自注意力、残差、归一化、前馈网络。
注意力数据流与张量形状数据流图Q、K、V 从哪来、怎么算、张量形状怎么变，以及多头到底拆的是什么。
LLM 推理管线数据流图从文本进来到 token 出去：分词、Prefill、Decode、采样、流式返回的全过程。

检索增强生成 ​

RAG 端到端链路、混合检索与重排的内部结构。RAG 是面试考察最密的领域，会连问三层。

图类型一句话
RAG 端到端管线数据流图离线索引与在线问答两条链路，以及在哪些位置可以插质量改进点。
混合检索与重排数据流图稠密与稀疏两路怎么各自召回、分数怎么融合、重排器在哪个位置介入。

训练与微调 ​

预训练 / SFT / 对齐的分工与数据管线，LoRA 等参数高效微调方法的注入位置。

图类型一句话
训练与微调方法分类架构图预训练、SFT、对齐三阶段的分工，以及全参微调与 LoRA 等参数高效方法的取舍。

科研文献 RAG 项目图 ​

面向无人水面艇与多智能体强化学习文献的检索问答服务：离线索引、双路召回、拒答、评测、门禁、服务化。

图类型一句话
科研文献 RAG 全景架构架构图一张图看清离线索引、在线问答、横切能力、评测闭环四个分区各自管什么、谁调用谁。
离线索引流水线数据流图从 PDF 到可检索索引，中间每一步的输入输出与落盘产物。
切块策略与分档消融流程图同一批文档用不同切法切出来，检索质量差在哪里、为什么。
双路召回、RRF 融合与精排数据流图稠密路与稀疏路各自召回，怎么融合、怎么精排、最后怎么拼上下文。
稀疏路自检失效（SPARSE_MODE=overlap）流程图让程序自己判断「这次要不要用稀疏路」，而不是永远开或永远关。
双层拒答决策流流程图程序层用分数阈值零成本拦一道，模型层再自报一次，两层误拒率分开测。
分层评测体系架构图检索侧和生成侧是两套独立的评测对象，指标不同、样本不同、结论不能互相代替。
回归门禁与三态退出码流程图把评测中确定性的那部分抽出来做成能进 CI 的门禁，用退出码表达三种结论。
服务冷启动到稳态状态图从进程起来到能扛流量，中间要过的几道状态，以及为什么健康检查不能只做一个。
一次问答的延迟分解时序图一个请求从进来到第一个字出去，时间到底花在哪一步。
前作与 YYHelp 的能力边界架构图两个项目不是「一个升级版」，而是回答了两个不同的问题。
