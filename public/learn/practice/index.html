面试自测台 ​

一句话：面经是「读」的，自测台是「练」的——59 道题，先自己答，再点开对照，自评结果存在本机浏览器。

▶ 在新窗口打开自测台（推荐，全屏更好用）

怎么用 ​

  1. 先答后看：看到题目先在脑子里（或纸上）过一遍骨架，再点「想好了，看答案」。
  2. 三档自评：会 / 模糊 / 不会——不要给自己打分虚高，「模糊」就是下一个要攻克的目标。
  3. 两级筛选：上方分组卡按主题筛（点一次进、再点一次出），右边的掌握度按钮按状态筛（未答 / 不会 / 模糊 / 会 / 全部）。默认落在「未答」，做完一批就自然推进。
  4. 键盘流：空格 显示/隐藏答案 · 1 会 · 2 模糊 · 3 不会 · r 重置记录。

三类题的出处不同，都要能指认

  • 项目题（24 道 = YYHelp 14 + RAG 10）：出处指向你项目的实测页面——答不出来说明经历没讲清。
  • 常识题（21 道）：出处指向站内知识体系 / 面经页（/interview/agent、/interview/rag、/interview/engineering）——这些是岗位必考，与项目无关也要会。
  • 开场题（6 道）：业界通用，没有标准答案，只有更好/更差的表述——对着镜子讲一遍比背答案有用。
