收件箱 ​

这里存放你在右侧对话助手里点「存为笔记」保存下来的回答。 想正式整理的内容，建议手动搬到 docs/kb/ 或 docs/projects/ 下再写进侧栏。

共 0 条。

怎么用 ​

右下角的对话助手回答完一个问题之后，如果你觉得这段值得留下，就把它存成笔记——不必是完整的知识，一句说清楚的话也算。

存下来的东西会变成 docs/inbox/ 下的一个 Markdown 文件，同时自动重建站点、自动进入助手的检索库。也就是说：你今天存的问题，明天助手就能引用它来回答你。

什么值得存 ​

值得存不值得存
你自己想通的类比或口诀直接把助手的整段回答原样存下来
面试里被问住、事后补上的那个点网上随手能查到的定义
对某个数字的口径追问结果你认为「以后可能有用」但没细看的内容
一个你自己发现的、和笔记矛盾的观察一次性的环境错误信息

这个收件箱不是终点

它是缓冲区，不是资料库。真正沉淀的地方是 知识体系（通用知识）和 项目拆解（你的项目）。收件箱里的条目攒到三五条、能归到某一层或某一页时，就动手搬过去——搬运的过程本身就是复习。

不要把它当日记

判断标准很简单：三个月后的你还看得懂、还用得上吗？ 答案是「不确定」就别存，写了也是给自己制造噪音。
