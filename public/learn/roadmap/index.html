学习路线总览 ​

一、我要去哪 ​

目标岗位（三选一，但共用同一份能力底座）

岗位面试官真正想看的东西对应的层
大模型开发工程师懂原理、能训能推、能算显存与成本L1 + L5 + L7
AI Agent 开发工程师能编排、能控状态、能兜底、工具契约扎实L4 + L2 + L5
AI 应用开发工程师能落地、能评测、能上线、能讲清取舍L3 + L5 + L6

三个岗位的共同底座是 L3 RAG + L4 Agent + L6 评测。这三层就是我的主战场。

二、总量核算 ​

层内容知识点估算学时
L0编程与工程基础30≈148h
L1大模型原理24≈103h
L2提示工程与结构化输出22≈71h

学时口径：从零基础到「能在面试中讲清楚并有代码产出」的净学习时间，不含反复练习与查资料。实际投入建议 ×1.5。

按每周 12 小时（课内 8h + 周末 4h）≈ 59 周；按每周 18 小时（含假期冲刺）≈ 40 周。

时间线：先确认再照做

这个站点建立于 2026-10-04。2027 届的招聘窗口是：

  • 提前批 2026 年 7—9 月（已过）
  • 正式批 2026 年 9—11 月（就在现在）
  • 春招补录 2027 年 3—5 月
  • 毕业 2027 年 6—7 月

所以真正的硬约束不是「学完 707 小时」，而是投递窗口。下面的阶段划分按这个现实重排过：先补能直接进面试口述与答题的部分，再补需要长期投入的部分。

三、三阶段（按投递窗口倒排） ​

阶段时间主题目标状态
A：面试止血现在 → 2026-11（≈6 周）L4 + L3 + L6 的高频考点，配我两个真实项目的深挖话术任何一场面试问到我的项目与 RAG/Agent 基础，都能答到三层追问
B：补齐底座2026-11 → 2027-02（≈14 周）L1 + L2 + L5 系统化补，L0 按需补（编码面单独刷）能解释上层现象、能算显存与成本、能讲清工程取舍
C：拉差距2027-02 → 2027-05（≈14 周）L7（SFT / LoRA / DPO / GRPO / 推理优化）+ 把两个项目再往深做一轮有微调与推理优化的真实数据，和「只会调 API」的人拉开距离

每周固定节奏：2h 读原理 + 6h 写代码 + 2h 写文档（README / 评测报告 / 笔记）+ 2h 复盘。

那 2 小时写文档的时间不能省 —— 简历素材与面试话术全部产自这 2 小时。学了但不写下来，等于没学。

四、阶段 A 的六周（最高优先级，每周一个硬性交付物） ​

顺序不是「章节顺序」，而是交付物顺序。每周必须产出一个能被面试官看到的东西。

周主题本周交付物（硬性）本项目里的落点
第 1 周Agent 骨架与状态机把 YYHelp 主图的节点、边、终止条件默画出来并讲清每个节点的职责YYHelp 总体架构
第 2 周ReAct 循环与工具契约讲清 @tool + pydantic 校验、幂等键、人工确认的完整链路工具层与 MCP
第 3 周检索层与中文 BM25 陷阱复现「Milvus 默认 analyzer 导致中文 BM25 静默返回空」这个故障YYHelp 检索层
第 4 周Rerank 与上下文组装拿出「加 Rerank 前后」的检索指标对比（至少两个数）重排与上下文组装
第 5 周评测与统计检验讲清配对 t / Wilcoxon / Holm 校正 / 效应量门槛 / 三态退出码YYHelp 评测与回归门禁

第 6 周结束的验收线：能用 3 分钟讲清「我的系统怎么工作 / 我改过什么 / 数据上是变好还是变差」，三个问题都拿得出数字。

六、编码面单开一条线 ​

L0 里的数据结构与算法不能靠「学完再看」，必须每天固定时间刷。建议：

  • 每天 1 题，周末 3 题，维持 8 个月 → 约 320 题
  • 高频顺序：数组 / 双指针 → 哈希 → 链表 → 二叉树 → 栈与队列 → 动态规划 → 图与搜索
  • 刷题时同时把每题的「思路一句话 + 复杂度 + 易错点」写进笔记，面试前直接翻
